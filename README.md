# Unnamed RP — Портал допуска

Веб-портал для ролевого проекта **Unnamed RP** на базе **Arma Reforger** с модом **ChernobylZone**.

## 🎮 О проекте

Это статический одностраничный веб-сайт, служащий порталом доступа для участников RP-сервера по вселенной S.T.A.L.K.E.R. Сайт предоставляет информацию о лоре проекта, новостях, фракциях и других аспектах игрового мира.

## ✨ Особенности

- **Атмосферный дизайн** — стилизация в духе вселенной S.T.A.L.K.E.R. с эффектами зернистости, виньетирования и характерной цветовой палитрой
- **Адаптивная вёрстка** — корректное отображение на различных устройствах
- **Система уведомлений** — встроенный механизм оповещений для игроков
- **Навигация по разделам** — быстрый доступ к основным разделам портала
- **Интеграция с GitHub Pages** — автоматический деплой при изменениях в main-ветке

## 📁 Структура проекта

```
.
├── index.html              # Основной HTML-файл со встроенными стилями и скриптами
├── assets/
│   └── images/             # Изображения (фоны, аватары, иллюстрации)
├── logos/                  # Логотипы фракций (PNG, 512×512px)
│   ├── dolg_logo.png       # Логотип «Долг»
│   ├── svoboda_logo.png    # Логотип «Свобода»
│   ├── bandits_logo.png    # Логотип бандитов
│   ├── mercs_logo.png      # Логотип наёмников
│   ├── military_logo.png   # Логотип военных
│   └── clearsky_logo.png   # Логотип «Чистое небо»
├── banners/                # Баннеры фракций (JPG/PNG, 600×200px)
│   ├── dolg_banner.jpg     # Баннер «Долг»
│   ├── svoboda_banner.jpg  # Баннер «Свобода»
│   ├── bandits_banner.jpg  # Баннер бандитов
│   ├── mercs_banner.jpg    # Баннер наёмников
│   ├── military_banner.jpg # Баннер военных
│   └── clearsky_banner.jpg # Баннер «Чистое небо»
└── .github/
    └── workflows/
        └── deploy-pages.yml  # Конфигурация GitHub Actions для деплоя
```

> **Важно:** Файлы логотипов и баннеров должны быть размещены в папках `logos/` и `banners/` соответственно. Подробные требования к изображениям описаны в файле [FRACTION_IMAGES.md](FRACTION_IMAGES.md). Если файлы не найдены, автоматически отобразятся SVG-заглушки с цветами фракций.

## 🚀 Развёртывание

Сайт автоматически развёртывается на **GitHub Pages** при пуше в ветку `main` благодаря настроенному workflow.

### Локальный запуск

Просто откройте `index.html` в любом современном браузере:

```bash
# Или используйте локальный сервер
python -m http.server 8000
```

Затем перейдите по адресу `http://localhost:8000`

## 🛠 Технологии

- **HTML5** — семантическая разметка
- **CSS3** — стилизация с использованием CSS-переменных, анимаций, backdrop-filter
- **Vanilla JavaScript** — интерактивность без внешних зависимостей
- **Google Fonts** — шрифты Russo One, Manrope, JetBrains Mono
- **GitHub Actions** — CI/CD через peaceiris/actions-gh-pages
